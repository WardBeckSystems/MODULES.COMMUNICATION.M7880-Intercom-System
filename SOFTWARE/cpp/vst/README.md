# Ward-Beck Systems M7880 Broadcast Intercom Station & IFB Ducker

The **M7880** recreates the iconic Ward-Beck Systems 7800-series intercom station from the MicroCOM II and MicroCOM III broadcast intercom systems. It brings authentic television studio talkback, talent IFB ducking, communications speech shaping, and multi-station matrix operation to digital audio workstations (DAWs) and live production environments.

## Features
- **10-Key Intercom Station**: 6 programmable destination keys (`DIR `, `PROD`, `CAM1`, `CAM2`, `SND `, `IFB1`) and 4 function keys (`CR1 `, `STU1`, `HOST`, `ALL `).
- **Dual Status Tallies**: Green LED (Incoming call / monitored listen) and Red LED (Talk / PTT active).
- **Red Alphanumeric LED Readouts**: 4-character 14-segment red LED displays showing station mnemonics.
- **Interruptible Foldback (IFB) Ducking**: Automatically ducks Program audio by -20 dB (configurable to -60 dB or full mute) with smooth attack/hold/release ballistics whenever Talkback or Call Chime is keyed.
- **Communications Speech Shaping**: Switchable Comms Bandpass (300 Hz HPF, 3.4 kHz LPF, +3.5 dB speech intelligibility peak at 2.0 kHz) and broadcast wideband modes.
- **Microphone Noise Gate / Expander**: Anti-click raised-cosine downward expander silencing studio HVAC and room rumble.
- **Station Speaker Cabinet Resonance**: Authentic 980 Hz metal cavity resonance and high-end roll-off modeling the 3-inch front panel speaker.
- **Call Alert Chime**: 1000 Hz / 2000 Hz dual-frequency broadcast alert tone.
- **Mechanical PTT Switch Clicks**: Authentic tactile switch transient modeling.
